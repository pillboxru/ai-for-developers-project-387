# Маршруты API регистрируются из контракта

Хекслет требует, чтобы серверные артефакты (типы, проверка запросов, маршруты) генерировались из спецификации. Поэтому маршруты API и проверку запросов и ответов регистрирует `fastify-openapi-glue` по OpenAPI, собранному из TypeSpec-контракта в `contract/`, а не вызовы `app.get`/`app.post` в `routes/`. Файлы `routes/*.ts` экспортируют обработчики операций, типизированные через hey-api, и по-прежнему вызывают сервисы.

## Considered Options

- Маршруты в `routes/` пишутся вручную, схемы берутся из сгенерированного OpenAPI. Привычнее для Fastify, но маршруты не генерируются из спецификации.
- Zod-схемы из hey-api и `fastify-type-provider-zod`. Валидация уходит от Ajv, а маршруты всё равно пишутся вручную.

## Consequences

- Новый эндпоинт начинается с правки контракта и `make generate`, только потом пишется обработчик. Glue находит обработчик по `@operationId`, поэтому он обязателен у каждой операции.
- Сгенерированный код не коммитится и не правится вручную.
- OpenAPI генерируется версии 3.0: с 3.1 Ajv в Fastify по умолчанию превращает `null` в `""`.
