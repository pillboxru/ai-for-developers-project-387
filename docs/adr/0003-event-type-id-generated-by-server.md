# id типа события генерирует сервер

В ТЗ сказано, что владелец задаёт id типа события. Мы отступили от этого: id генерирует сервер, а в форме владельца поля id нет. id нужен только для внутренних нужд, поэтому он скрыт от пользователя.

## Consequences

- Если клиент присылает id при создании типа события, сервер отвечает 400 с ошибкой «Неизвестное поле» у поля `id`, а не отбрасывает его молча.
